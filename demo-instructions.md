# 🎬 Demo Instructions for Smart Research Assistant

## Quick Testing Steps

### 1. Load the Extension
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (top right toggle)
3. Click "Load unpacked" and select the `smart-research-assistant` folder
4. The 🧠 icon should appear in your toolbar

### 2. Test on Sample Content
**Good test pages:**
- Wikipedia articles
- News articles (BBC, CNN, etc.)
- Blog posts with substantial content
- Research papers/documentation

### 3. Basic Functionality Test
1. Navigate to a content-rich page
2. Click the 🧠 Smart Research Assistant icon
3. Click "Summarize Page" - should generate a summary
4. Click "Generate Questions" - should create 5 research questions
5. Click "Save Current Research" - should save to notes
6. Click any question - should open Google search

### 4. Error Handling Test
- Try on pages with minimal content
- Test with pages that load content dynamically
- Verify error messages display properly

## 🛠 Troubleshooting Common Issues

### Extension Not Loading
- Check Chrome version (need Canary/Dev for AI APIs)
- Verify Early Preview Program access
- Check chrome://flags for AI-related flags

### AI APIs Not Working
- Ensure you're enrolled in Chrome Built-in AI Early Preview
- Check browser console for error messages
- Try on simpler content first

### Content Not Extracting
- Refresh the page and try again
- Check if page has substantial text content
- Try a different webpage
