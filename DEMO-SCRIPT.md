# 🎬 Demo Video Script (Under 3 Minutes)

## Opening Hook (15 seconds)
**[Screen: Chrome browser on a research-heavy webpage]**

"Hi! I'm about to show you how Smart Research Assistant transforms your research workflow using Google Chrome's built-in AI. This extension makes research more systematic, thorough, and completely private."

**[Action: Click extension icon in toolbar]**

## Problem Setup (20 seconds)
**[Screen: Multiple browser tabs open, showing typical research chaos]**

"When researching online, we often read passively, miss key insights, forget important follow-up questions, and lose track of what we've learned. Most AI tools require external services that compromise privacy and cost money."

**[Screen: Show popup interface opening]**

"Smart Research Assistant solves this by bringing AI directly into your browser."

## Feature Demo 1: Summarization (45 seconds)
**[Screen: Navigate to a Wikipedia article about AI or technology]**

"Let's test this on a complex Wikipedia article about artificial intelligence."

**[Action: Click 'Summarize Page' button]**

"Watch this - the extension uses Chrome's built-in Summarizer API to extract key insights..."

**[Screen: Show summary appearing in real-time]**

"Perfect! It's identified the main concepts and key points, saving me time from reading the entire article. This all happens locally on my device - no data sent to external servers."

## Feature Demo 2: Research Questions (40 seconds)
**[Screen: Same article, click 'Generate Questions' button]**

"Now for the really cool part - generating research questions to deepen my understanding."

**[Action: Click 'Generate Questions']**

"Using Chrome's Prompt API, it's creating thoughtful follow-up questions..."

**[Screen: Show questions appearing]**

"These questions help me think critically about the topic. I can click any question to instantly search Google."

**[Action: Click one question, show Google search opening]**

"This turns passive reading into active research."

## Feature Demo 3: Note Saving (30 seconds)
**[Screen: Back to extension popup]**

"I can save this research for later reference."

**[Action: Click 'Save Current Research']**

"The extension saves my summary, questions, and source with a timestamp. Everything stored locally for privacy."

**[Screen: Show saved notes section]**

"I can click saved notes to return to sources, building a personal research library."

## Technical Highlights (25 seconds)
**[Screen: Show code/architecture briefly or just extension interface]**

"This extension uses Chrome's Summarizer and Prompt APIs for local AI processing. It works offline, protects privacy, and costs nothing to run. The content extraction works across different websites, and the interface is designed for speed."

## Closing & Impact (25 seconds)
**[Screen: Back to clean extension interface]**

"Smart Research Assistant transforms how we research online. It's systematic, privacy-focused, and genuinely helpful. I'm submitting this to the Most Helpful Chrome Extension category because it meaningfully improves a workflow millions of people use daily."

**[Screen: Show final extension state with saved research]**

"Thanks for watching! The code is open source, and everything you need to try it is in the GitHub repository."

## Recording Tips

### Technical Setup
- **Resolution**: 1920x1080 minimum
- **Frame Rate**: 30 FPS
- **Audio**: Clear narration, no background music
- **Screen**: Clean browser window, close unnecessary tabs
- **Cursor**: Make sure cursor is visible and movements are smooth

### Content Preparation
- **Test Extension**: Make sure it works smoothly before recording
- **Prepare Test Pages**: Have Wikipedia article and other test content ready
- **Practice**: Run through the script a few times
- **Timing**: Keep strict 3-minute limit

### Best Practices
- **Speak Clearly**: Moderate pace, clear pronunciation
- **Show, Don't Tell**: Let the extension features speak for themselves
- **Smooth Transitions**: Practice moving between different features
- **Highlight Value**: Focus on how it solves real problems

### Demo Pages to Use
1. **Main Demo**: Wikipedia article on "Artificial Intelligence" or "Machine Learning"
2. **Backup**: BBC News technology article
3. **Alternative**: Mozilla Developer Documentation page

### Common Mistakes to Avoid
- Don't spend too long on installation/setup
- Don't show errors or bugs
- Don't get distracted by side features
- Don't exceed 3-minute limit
- Don't forget to mention the APIs used

### Upload Checklist
- [ ] Video under 3 minutes
- [ ] Shows functioning application clearly  
- [ ] Includes narration explaining features
- [ ] Mentions APIs used (Summarizer, Prompt)
- [ ] Uploaded to YouTube/Vimeo as public
- [ ] Video title includes "Smart Research Assistant" and "Chrome Built-in AI Challenge"
